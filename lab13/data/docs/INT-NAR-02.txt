# Аналітичний звіт щодо наративу «Колапс критичної інфраструктури»

## Загальна характеристика

Наратив NAR-02 «Колапс критичної інфраструктури» об'єднує 8 тверджень. Звіт складено групою моніторингу для внутрішнього використання; він містить ідентифікатори акаунтів і публікацій, тому має гриф обмеженого доступу.

## Твердження та стан перевірки

CLM-09: «Львів залишиться без води на два тижні». Пріоритет — середній; вердикт VRD-07: «фейк» (впевненість — середній), виніс Аналітик Ф-05 (здоров'я та медицина). Спростовано офіційним джерелом Офіційні канали міських рад (OFF-03). Публікацій із цим твердженням: 4, першоджерело: PUB-032 від ACC-001 (Анонімний Telegram-канал #1).

CLM-10: «Одеса залишиться без води на два тижні». Пріоритет — високий; вердикт VRD-08: «фейк» (впевненість — середній), виніс Аналітик Ф-04 (соцмережі й боти). Спростовано офіційним джерелом Офіційні канали міських рад (OFF-03). Публікацій із цим твердженням: 4, першоджерело: PUB-036 від ACC-002 (Анонімний Telegram-канал #2).

CLM-11: «Усі лікарні Харкова переведено на аварійне живлення без запасу пального». Пріоритет — високий; перевірку ще не завершено. Публікацій із цим твердженням: 5, першоджерело: PUB-040 від ACC-003 (Анонімний Telegram-канал #3).

CLM-12: «Усі лікарні Запоріжжя переведено на аварійне живлення без запасу пального». Пріоритет — середній; вердикт VRD-09: «фейк» (впевненість — середній), виніс Аналітик Ф-06 (фінансові шахрайства). Спростовано офіційним джерелом Офіційні канали міських рад (OFF-03). Публікацій із цим твердженням: 4, першоджерело: PUB-045 від ACC-004 (Анонімний Telegram-канал #4).
