# Сценарій демонстрації (7 хвилин)

## Перед показом

1. Запустіть Docker Desktop і Ollama з моделлю qwen2.5:7b.
2. У теці `lab16` виконайте `docker compose -p hub16 up -d --build`.
3. Відкрийте UI: http://127.0.0.1:8501. Документація API: http://127.0.0.1:8000/docs.
4. Автоматичний прогін тих самих кроків з перевіркою очікувань — `python demo/run_demo.py`. Результат зберігається в `demo/demo_run.md`.

## Запасний план

- Якщо Ollama недоступна, кроки 2–4a повертають HTTP 503 з поясненням. Їх показуємо з журналу `demo/demo_run.md` останнього прогону.
